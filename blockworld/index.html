About

Blockworld is a real 3D, first-person block game from Ttvm Studios. You look around in full 3D, explore mountains and dig into caves, fight with swords and build whatever you want, block by block.

It's being made to run fast, so even low-end PCs get high FPS. Right now it's in Alpha / Beta testing, not a full release yet. This page gets updated as stuff gets added.
