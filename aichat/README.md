# AI Chat

A free, fully customizable AI chat site. Static site, no backend, no cost.

- Talk to an AI for free using your own free Google AI Studio API key (aistudio.google.com/apikey, free tier, no card).
- Customize the AI's name, tagline, personality and extra instructions.
- Pick the model, accent color, light/dark theme.
- Chat history is saved in your browser. Your API key never leaves your device except to Google.
